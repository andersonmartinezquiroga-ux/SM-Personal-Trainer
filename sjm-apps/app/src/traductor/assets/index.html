Privacidad y pruebas

Estado del proyecto SJM

Esta versión permite traducción real por turnos cuando funciona el servicio en línea; no demuestra simultaneidad permanente, baja latencia garantizada, rendimiento con ruido ni hardware propio. El auricular privado y el módulo de solapa siguen siendo una fase de diseño físico. Puedes usar los audífonos Bluetooth que ya tengas según el audio del sistema Android.

El navegador puede enviar el audio del micrófono a su servicio de reconocimiento. Para voz suele ser necesario Chrome, internet y permisos. No se usa la voz Live de ChatGPT; el audio de salida depende de voces instaladas.

MyMemory es una API pública con límite gratuito y calidad variable. No se garantiza disponibilidad, traducción médica, jurídica ni uso para emergencias.
