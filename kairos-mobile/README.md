# KAIRÓS Móvil V0.1 (prueba)
Proyecto Android independiente para el Motorola del fundador SJM.
Funciones inicialmente admitidas: notificación local y solicitud de apertura de **tres** aplicaciones permitidas (Chrome, Gmail y MacroDroid), o el dominio SJM en navegador. **No** lee la pantalla, no toca botones, no envía formularios ni mensajes. No da acceso a otros sitios.
Para instalar: descargar `KairosMobile-debug-APK` del workflow en la rama feature/kairos-mobile-v1 y abrir `app-debug.apk`. El usuario debe confirmar instalación y habilitar Accesibilidad voluntariamente. En CONTROL 360 > Mentor > KAIRÓS 03 crear código temporal de emparejamiento, ingresarlo en la aplicación y activar el servicio. Nunca compartir secretos por chat. Se conserva MacroDroid KAIRÓS 02 sin modificaciones.
La vinculación queda pendiente hasta que se haga una prueba verificable en el Motorola. El envío de un intent de apertura no demuestra que una pantalla específica se haya abierto.
Un APK de depuración es para pruebas privadas, no distribución masiva ni Play Store.
